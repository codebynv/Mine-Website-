# Media Guidelines

## Adding media

- Use descriptive filenames.
- Prefer web-friendly formats where practical.
- Check dimensions and file size before committing.
- Verify playback for audio and video.
- Remove duplicate or obsolete assets when they are no longer referenced.

## HTML references

Before committing a media change:

1. Confirm the relative path is correct.
2. Open the affected page.
3. Check browser console output.
4. Test the asset on a narrow viewport.

## Repository hygiene

Do not commit temporary exports, editor metadata, local environment files, or unrelated generated assets.
