# Website Accessibility Checklist

- [ ] Images have useful alternative text when informative.
- [ ] Links have meaningful labels.
- [ ] Keyboard focus is visible.
- [ ] Text contrast is sufficient.
- [ ] Headings follow a logical hierarchy.
- [ ] Audio and video controls are usable.
- [ ] Layout works at zoomed and narrow viewport sizes.

Check accessibility alongside visual polish for each meaningful page change.
