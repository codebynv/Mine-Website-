# File Naming Guidelines

Use predictable filenames for assets and pages.

## Recommended

- Lowercase or consistent casing
- Descriptive names
- Hyphens or underscores used consistently
- Avoid spaces when practical

## Media

Prefer names that describe the content rather than generic names such as `new.mp4` or `final2.jpg`.

Before renaming an asset, search the repository for references so links and HTML paths are not broken.
