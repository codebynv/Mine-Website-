# Video Delivery Checklist

Before publishing or replacing a video asset:

- Confirm the intended source and usage rights.
- Check codec, container, dimensions, and file size.
- Verify audio is present and synchronized.
- Test playback on desktop and mobile.
- Provide captions or a transcript when appropriate.
- Avoid autoplay with sound.
- Confirm the page has a useful fallback if playback fails.

Check the actual delivered file rather than relying only on its filename.
