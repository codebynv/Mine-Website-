# Website Maintenance Notes

## Before publishing changes

- [ ] Test the main pages in a desktop browser.
- [ ] Check the layout at a narrow mobile width.
- [ ] Verify media files load correctly.
- [ ] Check internal links.
- [ ] Remove temporary files that are no longer needed.
- [ ] Confirm no local environment files or secrets are included.

## Media changes

When adding or replacing media:

- Use descriptive filenames where practical.
- Keep source assets organized.
- Check file size before committing large media.
- Verify audio and video playback after changes.

## HTML changes

For page updates:

1. Make the smallest focused change.
2. Open the affected page locally.
3. Check browser console errors.
4. Verify the visual result before committing.

## Git hygiene

Avoid committing editor settings, OS-generated files, logs, or local environment configuration.
