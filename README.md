## ✨ About the Project

**EditByNV** is a front-end portfolio website created to present a video editor's creative work in a more interactive way than a traditional resume or static portfolio.

The project combines **dark cinematic styling, responsive layouts, video previews, audio playback, portfolio sections, service cards, social links, and animated UI interactions** into a standalone website that can run directly in a browser.

The repository contains multiple iterations of the portfolio, including a more focused cinematic editor landing page and a broader multi-section portfolio interface.

## 🎨 Design Highlights

### 🌑 Cinematic Dark UI
The interface uses a dark background with warm red/orange accents to create a visual style suited to video editing and creative work.

### ✨ Micro-interactions
Hover states, transitions, animated navigation indicators, reel hover effects and quote rotation make the interface feel more dynamic.

### 📱 Responsive Layout
The CSS includes responsive behaviour for smaller screens, including mobile navigation adjustments, flexible video cards and stacked content layouts.

### 🎞️ Media-first Presentation
Instead of relying only on screenshots, the portfolio uses actual video and audio elements to let visitors experience the work directly.

## 🚀 Run Locally

No Node.js, package manager or build step is required.

### Option 1 — Open directly

```text
1. Clone the repository
2. Open john.html or lol.html
3. Explore the portfolio in your browser
```

### Option 2 — Use VS Code

```bash
git clone https://github.com/codebynv/Mine-Website-.git
cd Mine-Website-
```

Then open the project folder in **VS Code** and use **Live Server** for the best development experience.

> Because the project references local media files, keep the HTML files and their media assets in the repository structure when running the portfolio.

---

## 📸 Media Showcase

The portfolio is designed around real media assets rather than placeholder cards. Video files in the repository are connected directly to the HTML5 `<video>` elements, while audio files are used through native `<audio>` controls. fileciteturn11file0

This makes the project useful as a simple starting point for a **personal editor portfolio, showreel website, or creative media landing page**.
